Googleスプレッドシート連携 (GAS WebApp URL)

Googleスプレッドシートの「Apps Script」で作成したウェブアプリURLを設定すると、送信ボタンを押した瞬間にリアルタイムでスプレッドシートに追記されます。（未設定の場合はアプリ内保存とCSV出力をご利用いただけます）

【Google Apps Scriptの設定方法】

  1. スプレッドシートを開き、「拡張機能」>「Apps Script」を開く。
  2. コードを全消去し、以下のコードを貼り付けて保存する。
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.date, data.student, data.subject, data.tag, data.content]);
  return ContentService.createTextOutput("Success");
}
  1. 右上の「デプロイ」>「新しいデプロイ」をクリック。
  2. 種類で「ウェブアプリ」を選択。アクセスできるユーザーを「全員」にしてデプロイ。
  3. 発行された「ウェブアプリURL」を上の入力欄に貼り付けて保存してください。

よく使うキーワード（定型文）の編集

記録入力画面でワンタップ入力できる定型文フレーズを設定します。（1行に1つ）

クラス児童名簿の登録

1行に1人ずつ児童の名前を入力してください（例: 01 青木 太郎）。

教科・領域リストの設定

カンマ（ , ）区切りで教科や領域を追加できます。

データクリア・初期化

この端末に保存されている「現れの記録」を消去します。
